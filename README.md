SQL Projects: Book Sales & Hospital Data Analysis.

Overview
This repository contains two SQL projects developed using MySQL to practice data querying, analysis,
and extracting meaningful insights from datasets.

1. Book Sales Analysis
Analyzed book, customer, and order data to explore sales trends, popular genres, customer purchasing behavior,
revenue, book prices, and inventory levels.
Key SQL concepts: Filtering, aggregate functions, JOINs, GROUP BY, HAVING, sorting, and subqueries.

2. Hospital Data Analysis
Analyzed hospital data to explore patient statistics, department-wise patient distribution, medical expenses,
hospital stays, and monthly expense trends.
Key SQL concepts: Aggregate functions, GROUP BY, JOINs, date functions, conditional filtering, and sorting.

Tools Used
- MySQL
- MySQL Workbench
- SQL

Objective
To strengthen SQL querying and data analysis skills by solving practical business and healthcare data problems.
